# api参考总览

> 按调用目标和凭证类型选择企业管理接口或网关 AI 模型接口。

## 模型接口协议

使用 Chat Completions、Responses、Messages 等协议时，按对应协议选择请求路径、凭证和消息格式。所选模型与供应商决定支持的协议、可选参数、流式行为和工具能力。

| 接口类型       | 适用任务                    | 使用凭证                  | 开始位置                                                                                             |

| 网关管理接口     | 管理企业账号、项目角色、项目、统计和 BYOK | 按具体接口文档               | [认证与签名](api-ren-zheng-yu-qian-ming-ban-fa.md)                                                    |
| 网关 AI 模型接口 | 调用路由、文本向量化和聊天补全         | 当前账号在当前项目中的项目 API Key | [聊天补全](liao-tian-bu-quan.md) / [文本向量化](wen-ben-xiang-liang-hua.md) / [路由调用](lu-you-diao-yong.md) |

## 调用前检查

* 确认选择的是企业管理任务还是项目内模型调用，并使用对应凭证。
* 模型调用地址从当前项目复制；企业管理与统计接口使用对应接口文档指定的地址，不混用调用地址或重复追加版本路径。
* 按所选模型和供应商的能力使用可选参数，工具、推理、联网与流式用量并非所有模型通用。
* 凭证写入安全环境变量或密钥管理服务，不提交到代码仓库和日志。
* 保存请求标识，并在当前项目的调用日志或对应管理结果中核对调用结果。
