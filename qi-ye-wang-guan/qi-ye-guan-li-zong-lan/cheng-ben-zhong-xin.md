# 成本中心

> 按项目、成员和模型归集企业支出，解释费用来源，并导出财务核对依据。

## 成本中心解决什么问题

成本中心面向主账号、系统管理员和财务对账人员，按项目、成员、模型等维度归集支出、识别主要开支，并导出财务核对依据。使用平台模型的企业同样可以完成这些任务；普通成员不进入企业成本中心。 例如月底核对各业务支出时，按项目汇总找到主要费用，再切换成员或模型维度解释来源，最后导出同一筛选范围交给财务。

## 按任务选择正确页签

按项目归集支出后，可继续按成员或模型核对；不使用 BYOK 也可进行成本分析。

| 页签   | 适合完成的任务             | 不会替代      |
| ---- | ------------------- | --------- |
| 成本聚合 | 按项目、账号、模型等维度比较平台消费  | 企业概览的经营趋势 |
| 消费明细 | 查看筛选范围内的逐条消费事实并继续穿透 | 调用日志的项目排障 |
| 导出任务 | 查看导出创建、处理和下载结果      | 在线筛选结果    |

## 先确定查询范围

1. 选择需要核对的日期范围，基础版单次查询与现有格式导出最长31天，企业版最长180天；首尾日期均计入，允许跨月和历史区间，仅访问实际保留的数据。现有成本查询维度不另设套餐门槛。
2. 按项目、账号、模型、项目 API Key 或页面提供的其他条件缩小范围。
3. 确认筛选只是缩小数据范围，不会自动改变当前分组维度。
4. 等待金额、数量和明细使用同一组筛选后再核对。

## 从聚合穿透到明细

点击某个聚合结果进入消费明细时，页面保留当前日期和筛选，并追加该行的项目、账号或模型条件。这样可以解释聚合金额来自哪些记录。

## 理解平台消费与 BYOK 费用

平台消费包含平台渠道直连和 BYOK 回退到平台渠道后产生的费用；企业 BYOK 自有供应商账户账单不进入平台消费合计。

> **影响与边界**：BYOK 自有账户费用不应显示为 0 元平台消费。需要同时核对供应商账单时，应在企业自己的供应商账户中完成。

## 核对到单次调用

从消费明细打开单次详情，核对请求 ID、项目、调用账号、模型、接入方式、Token 和平台费用。需要项目上下文或性能排查时，使用请求 ID 回到对应项目调用日志。

## 创建并获取导出

1. 在成本聚合或消费明细中完成筛选。
2. 导出沿用页面已生效查询条件；确认导出范围后创建任务。
3. 进入「导出任务」查看处理中、成功或失败结果。
4. 任务成功后在有效期内下载；失败时按页面原因修正后重新创建。
5. 可从[通知中心](../kai-shi-shi-yong/tong-zhi-zhong-xin.md)查看本人导出任务的结果；实际下载仍以任务页面当前权限和有效期为准。

## 与其他页面核对时保持同一口径

* 企业概览用于看企业整体趋势和主要来源。
* 项目分析用于看当前项目或个人的使用结构。
* 调用日志用于排查项目内单次完成调用。
* 成本中心用于企业平台消费核对和导出。
* 对比时必须使用相同日期、项目、模型类型、权限范围和费用边界。

## 金额对不上时按顺序检查

1. 确认日期、项目、账号、模型和分组条件一致。
2. 确认比较的是平台消费，没有混入 BYOK 自有账户账单。
3. 确认当前账号拥有相同的数据范围。
4. 从聚合穿透明细，再用请求 ID 核对单次详情和项目调用日志。
5. 仍无法解释时保留筛选条件、请求 ID 和导出任务编号提交支持。
