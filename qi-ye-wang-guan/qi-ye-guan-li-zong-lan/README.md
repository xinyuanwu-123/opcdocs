# 企业管理总览



> 在企业范围管理项目与账号，核对成本，并维护接入凭证与安全规则。

## 选择要完成的任务

* [企业概览](qi-ye-gai-lan.md) — 在企业范围查看消费、请求、趋势和项目排行，并保持统计口径一致。
* [企业名称](qi-ye-ming-cheng.md) — 查看当前企业名称，需要时由主账号修改。
* [套餐与权益](tao-can-yu-quan-yi.md) — 查看当前套餐、有效期和资源上限，确认功能与查询范围。
* [项目管理](xiang-mu-guan-li.md) — 创建、进入、暂停、恢复和删除企业项目，并理解不同状态对调用的影响。
* [成本中心](cheng-ben-zhong-xin.md) — 按项目、成员和模型归集企业支出，解释费用来源，并导出财务核对依据。
* [账号管理](zhang-hao-guan-li.md) — 由主账号维护企业子账号的创建、账号级身份、密码、项目关系和删除。
* [项目角色](xiang-mu-jue-se.md) — 用角色模板统一项目内操作权限和预算、请求速率限额；具体模型授权在项目内配置。
* [BYOK](byok.md) — 接入企业自有模型供应商，打通企业模型、项目权限、调用验证和故障回退。
* [企业 AccessKey](qi-ye-access-key.md) — 创建和轮换企业级管理接口凭证，设置有效期并管理启用状态。
* [安全设置](an-quan-she-zhi.md) — 限制企业模型调用来源，并管理登录与敏感操作的二次验证。
* [操作审计](cao-zuo-shen-ji.md) — 追查企业关键管理变更，核对操作者、来源、对象与结果。
