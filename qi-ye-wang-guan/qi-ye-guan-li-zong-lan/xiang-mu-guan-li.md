# 项目管理

> 创建、进入、暂停、恢复和删除企业项目，并理解不同状态对调用的影响。

## 用项目划分业务边界

当企业有研发测试、客服助手等不同业务时，用项目分别管理成员、可用模型和调用记录，并在成本中心比较各项目支出。创建项目后还要核对成员、角色和模型；只有项目名称并不代表员工已经具备调用权限。

## 进入项目列表

主账号和系统管理员从企业级导航进入“项目管理”，创建和维护项目。普通成员只进入已获授权的项目；财务对账人员的费用核对由成本中心承接。

进入项目、管理项目和查看状态从同一列表开始。

## 创建项目

1. 在企业管理的「项目管理」点击「创建项目」。
2. 填写项目名称，确认后点击「创建项目」。
3. 返回项目列表，找到新项目并点击项目名称进入工作区。
4. 按需要分别进入「项目成员」「模型管理」和「路由策略」完成配置，再用目标成员的项目 API Key 验证调用。

> **需要注意**：创建表单只填写项目名称。成员、模型和路由需要进入项目后分别配置；创建成功不代表成员已经具备调用条件。

## 进入项目工作区

项目名称是进入工作区的主入口。进入后顶部项目选择器显示当前项目，分析、日志、成员、模型、路由和 API Key 都按当前项目隔离。

## 暂停与恢复调用

暂停项目后阻断新的模型调用，但保留成员、模型、路由、凭证配置和历史数据。恢复后原有配置继续生效。

> **影响与边界**：暂停前先确认业务影响。正在处理中的请求和异步任务按正式状态规则执行，不要把暂停当作删除。

## 系统冻结状态

系统冻结的项目进入只读或受限状态，页面会说明冻结原因。用户不能自行恢复，需要按页面指引处理。

## 删除项目

企业当前仅剩的唯一项目不可删除。企业存在至少两个项目时，`Default Project` 与其他项目使用相同删除规则；删除前检查成员、API Key、模型、路由和未结束任务等依赖，存在未解除依赖时页面阻止删除并给出处理入口。
