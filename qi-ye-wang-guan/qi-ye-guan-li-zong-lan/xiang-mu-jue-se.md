# 项目角色

> 用角色模板统一项目内操作权限和预算、请求速率限额；具体模型授权在项目内配置。

## 用模板统一成员的权限和限额

多个员工需要相同职责时，先建立项目角色，再为成员绑定，避免逐人重复配置。例如研发成员可以使用模型，项目管理员还可以维护项目。修改同一模板会影响引用它的成员，调整前应确认影响范围。

## 角色模板的作用域

角色在企业级统一维护，成员在具体项目绑定角色，获得操作权限与用量限额。账号级身份决定企业管理入口；项目允许使用哪些模型，在目标项目的「模型管理」中核对。

## 创建角色

1. 进入企业管理的“项目角色”，点击“新建角色模板”。
2. 填写角色名称。
3. 选择「管理」「路由配置」或「仅查看」权限类型。
4. 设置预算、RPM、TPM 等用量限额（如适用）。
5. 保存后在项目成员中绑定该角色。

角色模板用于复用操作权限和用量限额。

## 配置操作权限

权限类型决定成员能查看或操作哪些项目页面。「仅查看」可查看项目和全局路由策略，也允许创建本人的项目 API Key；它不等于可以维护项目成员、模型、路由或编辑、删除已有配置。

## 核对项目可用模型

进入目标项目的「模型管理」，核对业务需要的模型是否在项目可用范围内，再使用目标成员自己的项目 API Key 验证。角色模板用于操作权限与预算、RPM、TPM 配置。

## 配置用量限额

日预算和月预算是用量限额的周期，不是企业版套餐的付费周期。同一成员多把项目 API Key 共用该成员在项目中的额度，参见[个人预算](../xiang-mu-gong-zuo-qu/ge-ren-yu-suan.md)。

| 限额  | 控制对象                 | 达到限制后的结果                     |
| --- | -------------------- | ---------------------------- |
| 预算  | 成员在项目内的个人用量限额，按日或月计算 | 按页面显示的周期检查剩余额度，达到限额时处理对应调用限制 |
| RPM | 每分钟请求数               | 超过上限的请求被限流                   |
| TPM | 每分钟 Token 数          | 超过上限的请求被限流                   |

## 编辑与删除

修改角色会影响所有引用该模板的项目成员。存在成员绑定或其他引用时，不允许直接删除；先解除引用并确认影响。
