# OPC 企业级 AI 大模型网关

## 1. **产品概述**

### 1.1 **产品简介**

OPC 企业级 AI 大模型网关是 <code class="expression">space.vars.mainname</code> 专属的企业级 AI 服务平台，提供统一高性能的模型接入能力，支持 200+ 主流大语言模型和多模态模型。通过智能路由、BYOK（自带密钥）、精细权限管理和全栈可观测性，帮助企业在数据安全的环境中高效使用 AI 生产力。

### 1.2 **核心功能**

* **统一接入**：单网关兼容大语言模型 + 多模态模型，覆盖聊天、向量嵌入等核心能力
* **智能路由**：基于规则实现模型切换、供应商替换，自动路由至响应最快的实例
* **BYOK 支持**：支持自有密钥托管，优先使用企业自有 API 密钥
* **权限管理**：RBAC 权限体系，支持多层级团队权限和子账号管理
* **成本管控**：为团队/项目设置 API 预算和速率限制
* **全栈可观测**：可视化展示 Token 用量、成本、延迟，支持审计日志

## **5. 供应商集成（BYOK）**

### 5.1 **功能说明**

BYOK（Bring Your Own Key）是企业自主托管第三方模型供应商 API 密钥的功能：

* 网关会**优先使用您配置的自有密钥**调用对应模型
* 若自有密钥触发速率限制或故障，默认回退到 <code class="expression">space.vars.mainname</code> 供应商继续调用
* 可手动设置"始终使用此密钥"，关闭回退机制

## **8. AccessKey 管理**

## **9. API 接入指南**

### 9.1 **认证方式**

企业网关 API 支持两种认证方式：

1. **JWT Token 认证**：适用于 Web 前端和短期访问场景
2. **AccessKey/SecretKey 签名认证**：适用于服务端调用和自动化脚本

### 9.2 **获取 AccessKey 和 SecretKey**

联系系统管理员通过企业网关管理后台创建 Access Key，创建成功后会获得：

| <p>Plain Text<br>JSON<br>{<br>"access_key_id": "AK_xxxxxxxxxxxxxxxxxxxx",<br>"secret_key": "SK_xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx"<br>}</p> |
| --------------------------------------------------------------------------------------------------------------------------------------------- |

**​⚠️ 重要提示**：

* secret\_key 只在创建时显示一次，请务必妥善保存
* 丢失后无法找回，只能重新创建或轮换

### 9.4 **签名算法**

**第 1 步：计算请求体哈希**

| <p>Plain Text<br>CODE<br>BodyHash = Hex(SHA256(RequestBody))</p> |
| ---------------------------------------------------------------- |

**第 2 步：构造待签名字符串**

| <p>Plain Text<br>CODE<br>StringToSign = HTTP 方法 + "\n" +<br>请求 URI + "\n" +<br>时间戳 + "\n" +<br>请求体哈希</p> |
| -------------------------------------------------------------------------------------------------------- |

**第 3 步：计算 HMAC-SHA256 签名**

| <p>Plain Text<br>CODE<br>Signature = Hex(HMAC-SHA256(SecretKey, StringToSign))</p> |
| ---------------------------------------------------------------------------------- |

## **10. 常见问题**

### 10.1 **账号相关**

**Q1：如何创建子账号？​**

A：主账号登录控制台后，进入"账号管理"页面，点击"创建用户"按钮，填写子账号信息并提交即可。

**Q2：子账号的权限有哪些？​**

A：子账号的权限由主账号或项目管理员分配，分为"成员"和"管理员"两种网关权限，以及在具体项目中的角色权限。

**Q3：如何重置子账号密码？**

**​**A：在"账号管理"页面，找到对应子账号，点击"重置密码"按钮（锁形图标）即可。

### 10.2 **项目相关**

**Q4：一个项目可以添加多少个成员？​**

A：项目成员数量没有硬性限制，但受限于您购买版本的子账号总数上限。

**Q5：项目到期后会发生什么？​**

A：项目到期后，API Key 将无法继续调用，建议提前续费或延长项目时间。

**Q6：如何删除项目？​**

A：在项目详情页，点击设置或更多操作按钮，选择删除项目。注意：删除后无法恢复。

### 10.3 **BYOK 相关**

**Q7：BYOK 密钥如何配置？​**

A：进入"供应商集成"页面，选择目标供应商，填写 API Key 等必填信息，配置启用开关和"始终使用此密钥"选项后提交。

**Q8：BYOK 密钥遇到故障会怎样？​**

A：默认情况下，BYOK 密钥遇到速率限制或故障时，会自动回退到 <code class="expression">space.vars.mainname</code> 供应商。如果开启了"始终使用此密钥"，则不会回退。

### 10.4 **AccessKey 相关**

**Q9：Access Key 和 Secret Key 丢失了怎么办？​**

A：Secret Key 只在创建时显示一次，丢失后无法找回。您需要轮换该 Access Key 的 Secret Key 或重新创建新的 Access Key。

**Q10：如何轮换 Secret Key？​**

A：在"AccessKey 管理"页面，找到目标密钥，点击"轮换"按钮，系统会生成新的 Secret Key 并立即使原 Secret Key 失效。

### 10.5 **API 调用相关**

**Q11：API 调用返回签名验证失败怎么办？​**

A：请检查以下几点：

* AccessKey ID 和 Secret Key 是否正确
* 时间戳格式是否符合 ISO 8601 标准
* 时间戳与服务器时间差是否超过 5 分钟
* 签名计算过程是否正确（Body 哈希、StringToSign、HMAC-SHA256）

**Q12：如何使用路由策略调用模型？​**

A：在 API 请求的 model 字段中填入路由策略 ID（格式：rp\_xxxxxx），系统会自动根据路由策略配置选择模型和渠道。
