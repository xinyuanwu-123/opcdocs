# 开始使用

> 按任务选择管理员入门、主站使用企业额度或 API 调用；日常操作可查工作区、通知与权限。

## 选择要完成的任务

* [主账号管理员入门](zhu-zhang-hao-guan-li-yuan-ru-men.md) — 第一次使用企业网关？从主站登录开始，按顺序准备员工账号和项目，再让员工完成第一次调用。
* [普通成员快速调用](pu-tong-cheng-yuan-kuai-su-shi-yong.md) — 已经加入项目？使用自己的 Default API Key 和项目里的模型完成第一次调用。
* [工作区与语言](gong-zuo-qu-yu-yu-yan.md) — 切换企业与项目工作区，设置界面语言，并找到当前页面的帮助。
* [通知中心](tong-zhi-zhong-xin.md) — 在列表中查看发生了什么，点击通知直达对应页面。
* [权限与可见范围速查](quan-xian-yu-ke-jian-fan-wei-su-cha.md) — 用一条判定链理解账号身份、项目关系、角色、模型与数据的最终可见范围。
