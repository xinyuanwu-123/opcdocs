# 工作区与语言

> 切换企业与项目工作区，设置界面语言，并找到当前页面的帮助。

## 知道自己正在管理什么

企业工作区用于跨项目管理账号、配置和成本；项目工作区用于某个业务的模型调用、成员协作和分析。切换前看清企业与项目名称，避免在错误的业务范围里修改配置。

## 确认正在操作哪个工作区

企业工作区处理企业范围的项目、账号和治理事项；项目工作区查看所选项目的模型、成员、调用和用量。切换前确认左侧名称，切换后核对页头与项目选择器。财务对账人员使用企业工作区，普通成员只进入获授权项目。

## 切换与返回

1. 从左上角项目选择器选择有权访问的项目。
2. 需要企业级管理时，使用企业管理入口；回到项目后再次核对项目名称。
3. 原项目被删除或失去访问权时，按页面提示进入仍可访问项目；暂未加入项目时联系管理员，完成授权后重新检查权限。

## 切换界面语言

使用顶栏的语言按钮切换中文或英文，选择立即生效，刷新后保持。企业、账号和项目的自定义名称保留原文。

## 按任务找帮助

* 当前页面操作不清楚：打开顶栏“本页帮助”，查看操作指引和当前页面文档。
* 想了解其他模块：展开侧栏“文档中心”，按开始使用、项目工作区、企业管理或 API 参考进入目录。
* 文档在新标签打开，网关原标签中的筛选和未提交输入保留；返回网关时重新核对项目。
