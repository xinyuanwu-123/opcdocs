# 在主站使用企业网关额度

> 绑定手机号后，在主站选择企业、项目和自己的 API Key，使用企业额度聊天、生图和生视频。以下以生图为例，无需编写代码或手动粘贴密钥。

## 开始前

请先确认管理员已为你创建企业子账号、加入目标项目，并配置可用模型和额度。你需要知道企业子账号的登录信息，并能接收本人手机号的短信。

> **已经绑定过手机号？**：如果企业子账号已绑定你登录主站使用的同一个手机号，可跳过绑定步骤，直接用该手机号登录主站。

## 在企业子账号中绑定手机

1. 登录企业网关，确认当前是管理员分配给你的企业子账号。
2. 点击左上角企业与账号菜单，选择“绑定安全手机”。
3. 填写你登录主站使用的手机号，按页面提示完成账号密码与短信验证。
4. 确认绑定成功。若菜单已显示“更换安全手机”，先核对现有手机号是否与主站登录手机号一致；一致时无需重复绑定。

① 打开左上角账号菜单；② 选择“绑定安全手机”。此图为原型操作示意，账号使用示例信息。

## 用同一个手机号登录主站

打开\{{space.vars.homeurl\}}，使用刚才绑定的同一个手机号登录。手机号与企业子账号绑定的号码一致，才能找到对应的企业账号；此处使用主站的登录方式。

## 进入模型的在线推理页面

1. 在主站打开“模型中心”，选择“图像生成”；也可直接打开图像生成模型列表。
2. 选择要使用的模型，进入模型详情页。
3. 打开“在线推理”。企业额度在具体模型页面选择，模型列表页只用于找模型。

① 选择“图像生成”；② 点击所需模型，进入详情页。模型列表会持续更新，图中模型仅作入口示例。

## 选择企业、项目和自己的 API Key

1. 点击模型页面右上角“使用账户”旁的账户名称，展开选择面板。
2. 选择所属企业，再选择对应项目和你自己的 API Key。
3. 选齐后核对页面显示的企业和 Key；展开面板还可确认项目。这里是选择已有 Key，无需复制或粘贴密钥。

按 ① 企业 → ② 项目 → ③ API Key 选择。使用示例企业和项目演示。

> **生成前再核对一次**：“个人账户”使用个人账户额度。需要使用公司额度时，请确认已选中目标企业；切换账号、项目或浏览器标签页后，重新打开“使用账户”核对。

## 输入提示词，开始生成

1. 在“在线推理”中输入提示词，按模型要求设置尺寸、数量等参数；需要参考图片时按提示上传。
2. 确认使用账户和参数后，点击“开始生成”。
3. 等待任务完成，在结果区域查看或下载图片；需要回看任务时打开“历史任务”。

① 选择“在线推理”；② 填写提示词和参数；③ 开始生成。此图使用示例账号，未提交生成任务。

> **需要注意**：选择企业额度后，仍受所选项目的模型权限和账号额度限制。查看用量时进入企业网关的同一项目，按账号和调用时间核对[调用日志](../xiang-mu-gong-zuo-qu/diao-yong-ri-zhi.md)或[项目分析](../xiang-mu-gong-zuo-qu/xiang-mu-fen-xi.md)。

## 生视频和聊天怎么用

* 生视频：在模型中心选择视频生成，打开模型的“在线推理”，按相同方式选择企业、项目和 API Key，再填写提示词、素材和视频参数。
* 聊天：打开AI 群聊，在“使用账户”中完成同样的选择，再选择模型并发送消息。

## 找不到企业、项目或 Key

* 找不到企业：核对主站登录手机号与企业子账号已绑定手机号是否一致；刚完成绑定时，重新登录主站后再试。
* 企业下没有目标项目：请管理员确认你已加入该项目；加入项目不会自动获得所有模型的使用权限。
* 项目下没有可用 Key，或提示 Key 已失效：到企业网关同一项目的项目 API Key检查自己的 Key 及状态，处理后回主站重新选择。
* 提示额度不足或模型不可用：核对所选企业和项目，请管理员检查企业余额、账号预算及项目模型权限。换一把 Key 不会增加账号额度。
