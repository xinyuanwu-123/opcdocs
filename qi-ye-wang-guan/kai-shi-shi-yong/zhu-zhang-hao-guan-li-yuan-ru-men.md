# 主账号管理员入门

第一次使用企业网关？从主站登录开始，按顺序准备员工账号和项目，再让员工完成第一次调用。

### 从胜算云主站进入企业网关

1. 打开登录页： <code class="expression">space.vars.homeurl</code>
2. 使用手机号和验证码登录；未注册手机号通过验证码登录即注册。已有账号可切换密码登录。
3. 主站登录成功后，打开右上角账号菜单，点击“企业网关”。



### 创建企业账号

1. 进入企业管理的“账号管理”。
2. 点击“创建用户”，填写页面要求的员工账号信息。
3. 设置员工第一次登录要使用的初始密码。
4. 创建成功后，确认员工账号出现在列表中。

### 选择一个项目角色

项目角色决定员工在项目里可以查看和操作什么。已有合适的角色就直接选择；没有合适的再创建。

1. 进入企业管理的“项目角色”。
2. 确认这个角色可以进入项目并使用接下来要选的模型。
3. 如果新建了角色，保存后再继续。



### 创建或选择项目

进入企业管理的“项目管理”。如果列表里已经有 `Default Project` 或其他合适的项目，直接选择；没有合适的项目再创建一个。后面的成员、模型和调用记录都会放在这个项目里。



### 将账号加入项目并绑定角色

1. 进入目标项目的“项目成员”。
2. 点击添加成员，选择刚创建的企业账号。
3. 为员工绑定上一步选择的项目角色并提交。
4. 回到成员列表，确认员工已经出现在当前项目中。



### 检查项目里有可用模型

进入目标项目的“模型管理”，确认列表里至少有一个员工可以使用的模型。记下这个模型的名称或模型 ID，员工第一次调用时会用到。



### 让员工登录并找到 Default API Key

1. 将企业网关登录地址、员工账号信息和初始密码安全交给员工。
2. 员工登录后，进入刚才加入的项目。
3. 打开“项目 API Key”，找到系统提供的 `Default API Key`。
4. 复制并妥善保存这个 Key，后面调用模型时需要填写。



### 填写调用信息

如果使用 Agent 或应用平台，兼容接口选择 OpenAI Compatible。Base URL 填写 对应的，API Key 填写员工自己的 Default API Key，模型填写上一步确认的模型 ID。Base URL 已经包含版本路径，不要再追加 `/v1`。



### 完成第一次调用

员工可以在 Agent 或应用平台里发一条简单消息，也可以复制下面的 Shell、Python 或 JavaScript 示例运行。收到模型返回的内容，就说明这次调用已经成功。

```
export SSY_API_KEY="YOUR_PROJECT_API_KEY"export SSY_BASE_URL="https://router.dt-unicom-ai.com/api/v1" curl "$SSY_BASE_URL/chat/completions" \  -H "Authorization: Bearer $SSY_API_KEY" \  -H "Content-Type: application/json" \  -d '{    "model": "deepseek/deepseek-v3",    "messages": [{"role": "user", "content": "你好"}],    "stream": false  }'
```



### 在调用日志验证结果

1. 回到刚才使用的项目，打开“调用日志”。
2. 按调用时间找到刚才那条记录；如果响应中有请求 ID，也可以用请求 ID 查找。
3. 确认记录里的账号、API Key 和模型与刚才使用的一致。



### 第一次调用成功后还可以做什么

* 需要使用企业自己的模型额度时，再配置 BYOK。
* 需要分流或故障切换时，再配置路由策略。
* 需要给不同应用分别管理 Key 时，再创建新的项目 API Key。
