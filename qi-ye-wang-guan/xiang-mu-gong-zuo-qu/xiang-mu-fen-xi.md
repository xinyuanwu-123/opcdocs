# 项目分析

> 从项目或个人范围判断模型使用规模、变化趋势和主要消耗来源。

## 先明确要回答的问题

项目分析是进入项目工作区后的默认页面，适合回答“当前项目或我本人用了多少、变化发生在什么时候、主要由谁或哪个模型产生”。单次调用排查不在这里完成。 例如本周项目费用上涨，先看趋势确认开始上涨的日期，再按成员或模型排序定位主要来源。

## 选择项目或个人范围

| 统计范围 | 适合谁               | 看到什么             |
| ---- | ----------------- | ---------------- |
| 项目   | 项目管理员和具备项目数据权限的角色 | 当前项目内有权查看的整体使用情况 |
| 个人   | 所有可进入项目分析的成员      | 本人在当前项目中的使用情况    |

> **需要注意**：普通成员固定查看个人范围时，不代表项目没有其他调用，只表示当前账号没有项目整体数据权限。

## 确定模型类型和分析周期

1. 确认顶部项目选择器显示的是目标项目。
2. 在大语言模型和多媒体模型之间选择本次分析对象。
3. 默认本月至今；可使用「过去 7 天」「过去 30 天」「本月」及套餐允许的最长周期快捷项，也可以手动选择日期。过去 30 天按连续天数计算，不等于上一个自然月。基础版单次查询最长31天，企业版最长180天，首尾日期均计入；仅访问实际保留的数据。
4. 等待趋势和下方维度明细刷新；比较顶部摘要前，另行确认卡片标明的周期。

## 先用摘要判断规模

顶部摘要分别显示当前项目成员数、本月或累计消费、LLM Token 和多媒体调用次数。消费卡片可独立切换本月与累计口径；核对时先读每张卡片的周期说明，不把它们都当作下方分析日期内的汇总。Token 是模型处理文本的计量单位，不等于字数；输入 Token 对应发给模型的内容，输出 Token 对应模型生成的内容。

> **需要注意**：页面费用只统计平台侧实际产生的费用，不包含企业 BYOK 自有供应商账户账单。

## 查看我的额度

「我的额度」只展示当前账号在当前项目的个人额度，不受分析日期或模型类型影响。侧栏底部也可悬停或用 Tab 聚焦查看姓名、项目、实际日/月周期、预算总额、已用与剩余；具体见[个人预算](ge-ren-yu-suan.md)。

## 用趋势找到变化发生的时间

在费用、请求次数和 Token 之间切换，观察峰值或持续变化。趋势按所选日期和模型类型展示；与顶部摘要比较前，先确认其本月或累计口径是否一致。

## 按成员、模型或 API Key 定位来源

* 成员维度用于找到主要使用者，适合管理者判断协作和配额分布。
* 模型维度用于比较模型使用量和费用，适合选型与成本分析。
* API Key 维度用于区分应用或环境；只展示当前账号有权识别的 Key。
* 排序只改变明细顺序，不改变上方摘要、趋势和当前筛选。

## 需要更深排查时进入正确页面

| 接下来要解决的问题                | 继续前往 |
| ------------------------ | ---- |
| 定位某一次请求、查看 Token、延迟或实际模型 | 调用日志 |
| 核对企业平台消费、穿透明细或创建导出       | 成本中心 |
| 调整项目可调用模型范围              | 模型管理 |
| 调整成员角色或核对角色配额            | 项目成员 |

## 没有数据或数字对不上时

* 确认当前项目、统计范围、模型类型和日期是否正确。
* 确认当前账号是否只有个人范围权限。
* 确认调用已经完成，并在调用日志中可以找到对应记录。
* 对比成本时确认没有把 BYOK 自有账户账单计入平台费用。
