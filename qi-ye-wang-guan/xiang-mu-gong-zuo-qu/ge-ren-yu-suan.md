# 个人预算

> 辨认当前账号、项目与日/月预算，查看已用和剩余，找到调整入口。

## 判断本人还能用多少

个人预算是管理员为你在某个项目设置的用量上限，用于控制个人消耗，不是主账号账户余额，也不是企业版套餐价格。看到剩余不足时，先核对姓名、项目和日/月周期，再联系有权限的管理员调整；换一把个人 Key 不会增加这份额度。

## 查看预算明细

1. 在侧栏底部找到“日预算”或“月预算”和剩余比例。
2. 鼠标悬停或用 Tab 聚焦该行，查看完整姓名、项目、实际日/月周期、预算总额、已用与剩余。
3. 姓名和项目名称只在明细中展示，较长时自动换行。

悬停或键盘聚焦后查看项目、本月周期、总额、已用和剩余；日预算按实际周期显示。

## 理解周期与范围

按当前配置显示日预算或月预算。预算属于本人在该项目中的个人限额，同一成员的多把项目 API Key 共用；它不是企业总预算、主站模力余额或企业版服务费。分析页改日期不会改变这份预算。

## 进入企业管理区后不显示个人预算

个人预算只在项目工作区展示，切换项目时同步更新。进入企业管理区后隐藏摘要和明细，返回项目工作区后显示所进入项目的预算。主账号、无可访问项目或无有效预算数据时不展示摘要。

## 预算不够或与预期不同

1. 先核对账号、项目和日/月周期，再查看已用与剩余。
2. 需要调整时，请有权限的管理员到[项目角色](../qi-ye-guan-li-zong-lan/xiang-mu-jue-se.md)核对限额，再在[项目成员](xiang-mu-cheng-yuan.md)确认角色绑定；侧栏摘要只用于查看。
3. 找不到摘要时，先确认已进入项目工作区，再核对当前身份、项目访问权和是否有有效预算配置。
