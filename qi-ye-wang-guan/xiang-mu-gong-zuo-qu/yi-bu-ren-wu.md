# 异步任务

> 按请求 ID 查找异步模型任务，跟踪处理状态并在有效期内查看详情。



## 什么时候使用

模型以异步方式处理请求时，先用异步任务确认处理状态，再按请求 ID 追踪结果。调用日志用于排查已形成的模型请求记录，成本中心用于费用归集；任务状态本身不是费用凭据。

## 入口与可见范围

从当前项目的“监控与分析 → 异步任务”进入。普通成员查看自己的任务，管理者按其权限查看；历史项目中的任务按个人归属展示。先确认所在项目，再查询任务。

## 查找并查看任务

1. 选择任务创建日期；搜索请求 ID、模型或状态。
2. 点击刷新，核对请求时间、模型／厂商与状态。任务仍在处理中时，可稍后再刷新。
3. 请求 ID 显示为链接时，点击进入任务详情。该入口会离开当前网关页面；也可以使用浏览器的新标签页打开方式。
4. 任务形成调用记录后，在调用日志按同一请求 ID 核对结果与费用。

按任务创建时间筛选；可点击的请求 ID 进入任务详情。

## 详情入口的有效期

任务详情入口需要有效任务 ID，且在创建后 24 小时内。超过有效期，请求 ID 不再提供详情链接，但仍可查看当前列表信息。入口过期不等于任务失败，也不代表请求记录或账单同步删除。

## 找不到任务或结果时

* 先检查项目、创建日期、搜索条件与账号可见范围。
* 请求 ID 不是链接时，检查任务是否超过 24 小时，或是否缺少有效任务 ID。
* 调用日志中未找到时，先确认任务状态，再按相同请求 ID 与日期查询。不能仅凭列表里有任务就认定调用完成或已经计费。
* 持续失败或长时间未完成时，保留请求 ID、模型、创建时间、状态与错误信息，供管理员或技术支持排查。页面没有取消或重试入口时，不应将刷新当作重新提交任务。
