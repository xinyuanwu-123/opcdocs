# 项目工作区

> 围绕一个项目完成模型接入、团队协作、预算查看和调用排查。

## 选择要完成的任务

* [项目分析](xiang-mu-fen-xi.md) — 从项目或个人范围判断模型使用规模、变化趋势和主要消耗来源。
* [调用日志](diao-yong-ri-zhi.md) — 用请求 ID 定位一次完成调用，核对模型、Token、性能、接入方式和平台费用。
* [异步任务](yi-bu-ren-wu.md) — 按请求 ID 查找异步模型任务，跟踪处理状态并在有效期内查看详情。
* [模型管理](mo-xing-guan-li.md) — 理解项目模型限制，比较模型能力与价格，并维护当前项目真正可调用的模型范围。
* [路由策略](lu-you-ce-le.md) — 在直连模型验证完成后，用统一路由 ID 配置权重、故障转移或混合调度。
* [项目成员](xiang-mu-cheng-yuan.md) — 把企业账号加入当前项目，绑定项目角色，核对操作权限和角色配额。
* [项目 API Key](xiang-mu-api-key.md) — 使用系统准备的个人 Default API Key 完成调用，再按应用、环境和安全边界管理其他 Key。
* [个人预算](ge-ren-yu-suan.md) — 辨认当前账号、项目与日/月预算，查看已用和剩余，找到调整入口。
