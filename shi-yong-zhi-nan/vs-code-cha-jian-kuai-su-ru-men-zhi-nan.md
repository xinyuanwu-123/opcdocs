# VS Code插件快速入门指南

> <code class="expression">space.vars.mainname</code>服务于开发者，支持多种AI编程助手插件和工具，通过安装这些插件，您可以在 VS Code 编辑器中直接调用各类大模型，无需切换浏览器或进行复杂配置。

以 `Cline-中文版` 为例，演示如何在 VS Code 中安装并调用<code class="expression">space.vars.mainname</code>插件。

## 安装插件

在 VS Code 中打开扩展市场，搜索「Cline-中文版」 。

![image.png](<../.gitbook/assets/image preview (8)>)

点击安装，即可完成插件安装。

或访问插件市场页面： [Cline-中文版](https://marketplace.visualstudio.com/items?itemName=shengsuan-cloud.cline-shengsuan)。

***

## 登录与授权

安装后，点击左侧侧边栏中的「Cline-中文版图标」。

![image.png](<../.gitbook/assets/image preview (9)>)

👉 关于API Key获取，请参考 [开发者快速入门文档](kai-fa-zhe-kuai-su-ru-men-zhi-nan.md)。

![image.png](<../.gitbook/assets/image preview (10)>)

点击「授权」→「打开Visual Studio Code」，系统将自动识别API供应商和<code class="expression">space.vars.mainname</code>API Key。

点击「开始」，即可体验Cline-中文版。

![image.png](<../.gitbook/assets/image preview (11)>)
