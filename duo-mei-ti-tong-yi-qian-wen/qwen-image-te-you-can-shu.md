# qwen image 特有参数

## 同步图像编辑模型

### 支持的模型

| 模型ID                     | 描述                               |
| ------------------------ | -------------------------------- |
| ali/qwen-image-edit      | qwen-image 图像编辑模型，仅支持输出一张图       |
| ali/qwen-image-edit-plus | qwen-image plus 图像编辑模型，支持输出1-6张图 |

### 特有参数

千问图生图同步参数

| 参数               | 类型      | 是否必需 | 说明                                                                                                                                                                                                                 | 约束/默认值                                               | 示例                                                                       |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------ | ---------------------------------------------------- | ------------------------------------------------------------------------ |
| model            | enum    | 必需   | 模型名称                                                                                                                                                                                                               | 枚举值：`ali/qwen-image-edit`、`ali/qwen-image-edit-plus` | ali/qwen-image-edit                                                      |
| prompt           | string  | 必需   | 正向提示词，描述生成图像中期望包含的元素和视觉特点                                                                                                                                                                                          | >= 1 字符， <= 1000 字符                                  | 将图中的人物改为趴姿势，伸手握住狗的前爪                                                     |
| image            | string  | 必需   | 需要编辑的图片URL                                                                                                                                                                                                         |                                                      | https://dashscope.oss-cn-beijing.aliyuncs.com/images/dog\_and\_girl.jpeg |
| n                | integer | 可选   | 输出图像的数量，默认值为1。对于 qwen-image-edit-plus、qwen-image-edit-plus-2025-10-30，可选择输出1-6张图片。对于 qwen-image-edit，仅支持输出1张图片。                                                                                                    |                                                      |                                                                          |
| negative\_prompt | string  | 可选   | 反向提示词，描述生成图像中期望排除的元素和视觉特点                                                                                                                                                                                          | <= 1000 字符                                           |                                                                          |
| size             | string  | 可选   | 设置输出图像的分辨率，格式为宽 \_高，例如 `"1024_ 2048"`。宽和高的取值范围均为 \[512, 2048] 像素。默认行为：若不设置，输出图像将保持与原图相似的长宽比，接近 1024\*1024 分辨率。使用限制：该参数仅在输出图像数量 n 为 1 时可用，否则将报错。支持模型：仅 qwen-image-edit-plus 和 qwen-image-edit-plus-2025-10-30 模型支持。 |                                                      |                                                                          |
| watermark        | boolean | 可选   | 是否添加水印标识                                                                                                                                                                                                           | 默认值：false                                            | false                                                                    |
| prompt\_extend   | boolean | 可选   | 是否开启prompt智能改写。开启后，将使用大模型优化正向提示词，对描述性不足、较为简单的prompt提升效果较明显。true：默认值，开启智能改写。false：不开启智能改写。支持模型：仅 qwen-image-edit-plus 和 qwen-image-edit-plus-2025-10-30 模型支持。                                                       |                                                      |                                                                          |
| seed             | integer | 可选   | 生成图片的种子                                                                                                                                                                                                            | >= 0 ，<= 2147483647，默认值：1                            | 1                                                                        |

## 图像生成模型

### 支持的模型

| 模型ID                | 描述                   |
| ------------------- | -------------------- |
| ali/qwen-image      | qwen-image 图像模型      |
| ali/qwen-image-plus | qwen-image plus 图像模型 |

### 特有参数

千问文生图异步参数

| 参数               | 类型      | 是否必需 | 说明                                                                                                                                    | 约束/默认值                                                                                                | 示例           |
| ---------------- | ------- | ---- | ------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------- | ------------ |
| model            | enum    | 必需   | 模型名称                                                                                                                                  | 值：`openai/gpt-image-1`                                                                                |              |
| prompt           | string  | 必需   | 正向提示词，描述生成图像中期望包含的元素和视觉特点                                                                                                             |                                                                                                       | 一只可爱的小猫坐在花园里 |
| negative\_prompt | string  | 可选   | 反向提示词，用于描述不希望在图像中出现的内容，对画面进行限制。支持中英文，长度不超过500个字符，超出部分将自动截断。示例值：低分辨率、错误、最差质量、低质量、残缺、多余的手指、比例不良等。                                       |                                                                                                       |              |
| size             | enum    | 可选   | 输出图像的分辨率，格式为宽 _高。默认分辨率为1328_ 1328。可选的分辨率及其对应的图像宽高比例为：1664\*928：16:9。1472\*1140：4:3 。1328\*1328（默认值）：1:1。1140\*1472：3:4。928\*1664：9:16 | 枚举值：`auto`、`1024x1024`、`1536x1024`、`1024x1536`、`256x256`、`512x512`、`1792x1024`、`1024x1792`；默认值：`auto` | 1024x1024    |
| prompt\_extend   | boolean | 可选   | 是否开启prompt智能改写。开启后，将使用大模型优化正向提示词，对描述性不足、较为简单的prompt有明显提升效果，但会增加3-4秒耗时。true：默认值，开启智能改写。false：不开启智能改写。                                  |                                                                                                       |              |
| watermark        | boolean | 可选   | 是否在图像右下角添加 "Qwen-Image" 水印。默认值为 false                                                                                                 |                                                                                                       |              |
| seed             | integer | 可选   | 随机数种子，取值范围 \[0,2147483647]。使用相同的seed参数值可使生成内容保持相对稳定。若不提供，算法将自动使用随机数种子。注意：模型生成过程具有概率性，即使使用相同的seed，也不能保证每次生成结果完全一致。                     |                                                                                                       |              |
