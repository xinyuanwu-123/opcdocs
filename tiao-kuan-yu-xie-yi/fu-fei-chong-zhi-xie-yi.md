# 付费充值协议

{% stepper %}
{% step %}
### 当您进行账户模力购买时，应仔细确认账号信息、支付方式、购买模力金额及服务需求，充分理解平台计费规则及服务内容（1元=1模力，消费时优先扣除赠送模力）

购买模力行为视为您对自身需求的明确确认，因您自身操作不当（如错选账号、错选模力购买种类）、需求变化、对服务理解偏差等非平台原因导致的模力购买问题，责任由您自行承担，原则上不支持退款。若您确有退款需求，需向平台客服提交申请并提供充分证明材料（如平台服务故障证明等）（电子邮箱详见官方网页最下方），平台将对退款事由进行严格审核，审核通过的，在扣除手续费等必要成本后按规则退回剩余未消费模力对应的金额。退款仅支持一次性退回账号内全部未消费模力余额，不支持部分退款；已消耗模力金额、已开具发票金额不予退回。
{% endstep %}

{% step %}
### 您使用付费服务前需预先购买模力，模力余额充足时可正常使用服务，模力余额不足时平台有权停止服务

您应自行承担未及时购买模力导致的责任与损失。平台在内部测试或活动期间可能提供免费使用额度，您可联系客服申领。开放平台的赠送模力、购买模力优惠模力、活动返利模力等非现金等价权益，均不可提现、不可转让、不可开具发票，且不纳入退款范围。
{% endstep %}

{% step %}
### 未消耗且未开具发票的购买模力余额，仅在因平台原因无法正常使用服务时，支持申请退款

未消耗且未开具发票的购买模力余额，仅在因平台原因（如服务中断、功能故障、政策调整导致服务终止等）无法正常使用服务时，支持申请退款。非平台原因（包括但不限于您主动放弃使用、需求变更、操作失误等）的未消耗模力余额，原则上不支持退款。
{% endstep %}

{% step %}
### 已消耗的服务对应的模力金额因服务已实际提供，一律不支持退款

已消耗的服务对应的模力金额因服务已实际提供，一律不支持退款；已开具发票但未消耗的模力对应的金额，需先在平台“发票管理”页面完成发票作废流程，且经平台审核确认发票状态无误后，方可申请退款（退款审核标准同条款3）。
{% endstep %}

{% step %}
### 对公汇款购买模力的金额不支持在线申请退款

对公汇款购买模力的金额不支持在线申请退款，如有退款需求，需联系平台客服并提供以下材料：购买模力凭证、企业营业执照、退款事由说明（需加盖企业公章）等（电子邮箱详见官网最下方）。平台将对材料真实性、退款事由合理性进行严格审核，仅在确认属于平台责任导致无法使用服务的情况下，方可启动退款流程，审核未通过的不予退款。
{% endstep %}

{% step %}
### 不同支付方式的退款申请受时间限制

微信、支付宝支付订单：自模力购买完成之日起超过12个月的，原则上不支持退款，特殊情况（仅限平台原因）需联系客服并提供充分证明，经专项审核通过后方可处理；

Paypal支付订单：自模力购买完成之日起超过180天的，不支持在线申请退款，特殊情况（仅限平台原因）需联系客服，经审核通过后按线下流程处理。
{% endstep %}

{% step %}
### 因计费系统可能存在延迟，申请时显示的可退款金额为预估金额

实际退款金额以平台最终核实的未消耗、未开票且符合退款条件的模力对应的金额为准，平台将在退款审核通过后告知您实际退款金额。
{% endstep %}

{% step %}
### 退款申请经平台审核通过后，将按原支付路径退回

退款申请经平台审核通过后，将按原支付路径退回，一般在10-15个工作日内到账，具体到账时间以支付渠道处理周期为准。审核未通过的，退款申请即时驳回，平台将通过短信或站内信告知驳回原因。
{% endstep %}

{% step %}
### 为确保退款流程有序处理，一个账号仅可存在一笔处理中的退款申请

且同一笔模力购买订单的退款申请仅支持提交一次，审核驳回后不再受理该订单的二次退款申请（平台原因导致的审核驳回除外）。
{% endstep %}
{% endstepper %}

本协议旨在规范模力购买与退款行为，保障平台服务的稳定性与可持续性。请您在购买模力前仔细阅读并理解本协议，购买模力行为即视为您同意本协议全部条款。
