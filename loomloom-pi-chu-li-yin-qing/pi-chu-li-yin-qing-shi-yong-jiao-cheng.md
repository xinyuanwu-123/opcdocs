# 批处理引擎使用教程

| <p><strong>批处理引擎</strong> 是我们推出的批量<strong>文本处理、图片处理、视频处理</strong>平台。 </p><p>📎 项目地址： <a href="http://github.com/SSYCloud/loomloom">github.com/SSYCloud/loomloom</a> </p> |
| ------------------------------------------------------------------------------------------------------------------------------------------------------------------------ |

**🧠 它是怎么工作的？**

批处理引擎 通过给 AI 安装「技能包（Skill）」来工作：用户用自然语言描述批处理需求，AI 自动调用 批处理引擎 CLI 完成上传、提交、等待、回填全流程。

**支持平台：** Codex（OpenAI）、Claude Code（Anthropic）、OpenClaw

**✨ 效果案例展示**

**📄 场景一：GitHub 项目函数批量单测**

存量代码库单测覆盖率低，人工逐个补写耗时且无从下手。

**真实案例：为开源项目**[**ember**](https://github.com/alexandre-daubois/ember)\*\* 批量补全单元测试\*\*

**怎么用：只需对 Agent说一句话 👇**

| 「请在 [https://github.com/alexandre-daubois/ember](https://github.com/alexandre-daubois/ember) 这个仓库里完成一个小型闭环任务，可以先拉取仓库到本地进行：使用 loomloom 的文本批处理模板，批量做"单元测试检查和生成"。找出当前测试里明显还缺的测试点，生成单元测试写入仓库，跑 go test 确保通过。」 |
| --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |

**Agent** 自动规划并执行完整流程：

1. **确认样本文件** — 扫描仓库，选取 internal/model/logbuffer.go 等目标文件
2. **上传文件 & 提交批处理** — Agent逐个调用 批处理引擎 CLI 上传代码文件拿到文件 ID，填入 Excel 模板（每行一个文件）后提交任务

![](<../.gitbook/assets/Unknown image (65)>)

1. 批处理引擎 多文件并行跑完，结果自动回填；每行对应一个文件的完整测试代码

![](<../.gitbook/assets/Unknown image (66)>)

1. Codex 将结果写入对应测试文件，本地执行 go test ./... -v，全部通过 ✅

![](<../.gitbook/assets/Unknown image (67)>)

十几个文件**同时并行处理，分钟级出结果**，仅用几毛钱，整个仓库的单测覆盖率一次性拉满。

**🎬 场景三—— 短剧批量生成分镜视频**

编剧写好分镜脚本后，导演/制片需要快速看「这集长什么感觉」，但人工出分镜图+动态效果费时费力。用 批处理引擎，**一集 30 个分镜批量跑完，直接变成一条粗剪故事板**。

**🛠️ 怎么用**

* **每一行 = 一个分镜**，填入画面描述 + 人物设定 + 视觉风格
* 「视觉风格」：电影级色调，冷暖对比，豪门宴会，16:9
* 视频时长选 4 秒（分镜节奏感），一集 30 镜一次跑完
* 结果自动回填 Excel：**30 条优化提示词 + 30 段视频**，直接剪成故事板预览

1.注册登陆网站后，点开控制台，部署云端openclaw

![](<../.gitbook/assets/Unknown image (78)>)

2.点击进入openclaw进行对话

![](<../.gitbook/assets/Unknown image (79)>)

3.将下面这段话复制发给openclaw

| 安装curl -fsSL [https://batchjob-test.shengsuanyun.com/loomloom/releases/latest/install-openclaw.sh](https://batchjob-test.shengsuanyun.com/loomloom/releases/latest/install-openclaw.sh) \| bash 密钥：替换成你自己的key |
