# 智能体农场

## 1. **产品简介**

智能体农场是 <code class="expression">space.vars.mainname</code> 提供的云端 OpenClaw 等智能体部署服务。用户可以在控制台中快速创建一个或多个“龙虾”实例，让龙虾在云端运行 OpenClaw 等智能体服务，为用户提供持续在线的智能体能力。

在本产品中，用户主要完成两类操作：一是在“创建龙虾”页面配置并部署龙虾实例，二是在“我的龙虾”页面查看、进入和管理已经创建的龙虾实例。龙虾部署完成后，点击“进入”会跳转到 智能体自身的网页界面。该界面不属于 <code class="expression">space.vars.mainname</code> 台产品范围，后续 OpenClaw 内部功能的使用请参考 OpenClaw 官方文档： [OpenClaw 官方文档](https://docs.openclaw.ai/zh-CN)。其他智能体的使用请参考对应智能体的官方文档。

## **2. 使用范围说明**

本文档只说明 <code class="expression">space.vars.mainname</code> 控制台内 OpenClaw 龙虾农场相关页面的使用方式，包括“创建龙虾”和“我的龙虾”两个页面的功能、字段含义和交互逻辑。

本文档不展开说明 OpenClaw 官方网页界面的具体使用方法。用户成功部署龙虾并点击“进入”后，如需了解 OpenClaw 网页界面中的聊天、配置、渠道、节点、会话等功能，请查看 OpenClaw 官方文档： [OpenClaw 官方文档](https://docs.openclaw.ai/zh-CN)。

## **3. 进入龙虾管理**

登录 <code class="expression">space.vars.mainname</code> 控制台后，在左侧导航栏中找到“龙虾管理”。展开该菜单后，可以看到两个功能入口：“创建龙虾”和“我的龙虾”。

“创建龙虾”用于新建并部署 OpenClaw 龙虾实例。“我的龙虾”用于查看已经创建的虾群和龙虾实例，并对实例进行进入、开机、释放等管理操作。

## **4. 创建龙虾页面概览**

点击左侧导航栏中的“龙虾管理 > 创建龙虾”，进入创建页面。该页面用于配置龙虾实例的部署区域、机器规格、镜像版本、存储容量、付费方式、虾群名称、龙虾数量、API Key、模型和渠道等信息。

页面顶部会展示当前配置的概要信息，包括内存大小、核数、镜像版本、到期时间、服务器数量和费用金额。用户在页面中调整配置后，顶部信息会用于辅助确认本次部署的资源规格和费用情况。

<figure><img src="../.gitbook/assets/image (12).png" alt=""><figcaption></figcaption></figure>

## **5. 顶部配置概要**

创建页面顶部展示当前即将部署的资源概要，主要包括内存大小、核数、镜像版本、到期时间、服务器数量和费用金额。

“内存大小”用于展示当前所选机器规格对应的内存，例如 2 GB。

“核数”用于展示当前所选机器规格对应的 CPU 核数，例如 2 核。

“镜像版本”用于展示当前选择的系统或 OpenClaw 镜像版本。

“到期时间”用于展示当前付费方式对应的服务到期时间；如果当前未形成明确到期时间，页面可能显示为“-”。

“服务器数量”对应本次部署的龙虾数量。

“费用金额”显示在页面右上角，用于提示当前配置预计产生的费用。

该区域主要用于确认信息，通常不需要用户直接编辑。用户需要通过下方配置项调整部署参数，顶部概要会根据配置结果展示对应信息。

## **6. 选择地区**

“选择地区”用于选择龙虾实例部署所在的云端区域。页面中以一个下拉框展示可选地区，例如“aliyun(南通)上海”。

用户点击下拉框后，可以查看当前支持的部署区域，并选择其中一个区域作为龙虾部署位置。选择地区会影响龙虾实例实际运行的云端环境，也可能影响网络访问速度、可用机器规格和资源供应情况。

如果用户没有特殊要求，通常可以保持系统默认选择。如果用户希望龙虾部署在特定地区，则需要在此处手动切换。

<figure><img src="../.gitbook/assets/Unknown image (38)" alt=""><figcaption></figcaption></figure>

## **7. 选择机器**

“选择机器”用于选择龙虾实例的服务器规格。页面中以一个下拉框展示可用机器规格，例如“2c2g”。

规格名称通常代表 CPU 和内存配置。例如“2c2g”表示该机器规格包含 2 核 CPU 和 2 GB 内存。用户选择不同机器规格后，页面顶部的“内存大小”和“核数”会随之对应变化。

如果用户只进行基础体验或轻量使用，可以选择较小规格。如果用户计划运行多个任务、长时间运行智能体，或需要更高稳定性，可以选择更高规格。实际可选项以页面下拉框展示为准。

<figure><img src="../.gitbook/assets/Unknown image (39)" alt=""><figcaption></figcaption></figure>

## **8. 选择镜像**

“选择镜像”用于选择龙虾实例启动时使用的镜像版本。页面中以一个下拉框展示可选镜像，例如“openclaw:0506.no-browser”。

镜像决定了龙虾实例中预置的运行环境和 OpenClaw 相关版本。用户点击下拉框后，可以从可用镜像中选择一个版本。选择完成后，页面顶部的“镜像版本”信息会显示当前镜像相关内容。

一般情况下，建议选择平台默认推荐的 OpenClaw 镜像版本。如果平台提供多个镜像版本，用户应根据自己的兼容性需求选择合适版本。

## **9. 基础盘大小**

“基础盘大小”用于展示龙虾实例默认系统盘容量。当前页面中基础盘大小显示为 20 GB。

该字段为信息展示项，不是可编辑输入框。用户无需手动填写基础盘容量。基础盘用于存放系统环境、基础运行文件以及镜像预置内容。

<figure><img src="../.gitbook/assets/Unknown image (41)" alt=""><figcaption></figcaption></figure>

## **10. 扩展盘大小**

“扩展盘大小”用于配置额外的数据盘容量。页面中通过滑块进行调整，右侧会显示当前扩展盘大小，例如 0 GB。

用户可以拖动滑块增加扩展盘容量。扩展盘适合用于存放更多运行数据、文件缓存或其他需要持久化保存的内容。默认情况下，扩展盘大小可能为 0 GB，即不额外增加扩展存储。

交互逻辑如下：用户向右拖动滑块，扩展盘容量增加；向左拖动滑块，扩展盘容量减少。滑块右侧显示的数值会随拖动变化，用于确认当前选择的扩展盘容量。

<figure><img src="../.gitbook/assets/Unknown image (42)" alt=""><figcaption></figcaption></figure>

## **11. 付费方式**

“付费方式”用于选择龙虾实例的计费模式。提供三个选项：按月付费、按年付费和按量付费。

用户点击任意一个付费方式按钮后，该按钮会变为选中状态。不同付费方式会影响费用计算、到期时间展示和资源使用规则。

按月付费适合预计使用周期较稳定、按月持续使用的场景。

按年付费适合长期使用场景。

按量付费适合短期体验、临时任务或使用时长不固定的场景。

当用户切换付费方式后，页面顶部的费用和到期时间可能会随之变化。实际费用以页面右上角展示结果为准。

<figure><img src="../.gitbook/assets/Unknown image (43)" alt=""><figcaption></figcaption></figure>

## **12. 虾群名称**

“虾群名称”用于为本次创建的龙虾实例组命名。页面会默认生成一个虾群名称，例如“虾群1778144265416”。

用户可以保留默认名称，也可以点击输入框后手动修改为更容易识别的名称。建议使用能够表达用途的名称，例如“客服助手虾群”“测试环境虾群”“项目A研发虾群”等。

虾群名称会在“我的龙虾”页面中显示，方便用户后续筛选、查看和管理对应的龙虾实例。

交互逻辑如下：点击输入框后可编辑名称；输入完成后，系统会在部署时使用该名称创建虾群；如果名称为空或格式不符合平台要求，提交部署时可能无法通过校验，用户需要根据页面提示补充或修改。

<figure><img src="../.gitbook/assets/Unknown image (44)" alt=""><figcaption></figcaption></figure>

## **13. 龙虾数量**

“龙虾数量”用于设置本次要创建的龙虾实例数量。页面中通过滑块进行调整，右侧会显示当前选择的数量，例如“1 只”。

用户可以拖动滑块增加或减少龙虾数量。龙虾数量会影响本次创建的服务器数量，也会影响费用。页面顶部的“服务器数量”和右上角费用会根据实际选择进行展示。

如果只需要一个 OpenClaw 实例，可以保持默认 1 只。如果希望同时部署多个云端龙虾为不同任务或不同用户服务，可以增加龙虾数量。

交互逻辑如下：向右拖动滑块，龙虾数量增加；向左拖动滑块，龙虾数量减少；右侧数量提示会同步变化；最终点击“立即部署”时，系统会按照当前数量创建对应实例。

<figure><img src="../.gitbook/assets/Unknown image (45)" alt=""><figcaption></figcaption></figure>

## **14. API Key**

“API Key”用于选择龙虾实例运行时调用模型所需的密钥。页面中以一个下拉框展示当前账号下可用的 API Key，例如“default”。

用户点击下拉框后，可以选择已经配置好的 API Key。被选中的 API Key 将用于本次部署的龙虾实例。部署完成后，龙虾会基于该密钥连接对应模型服务。

如果下拉框中没有合适的 API Key，用户需要先到控制台左侧的“API 密钥”页面进行配置，然后再返回创建龙虾页面选择。

交互逻辑如下：点击 API Key 下拉框，展开可选密钥列表；选择目标密钥后，下拉框显示当前选择；点击“立即部署”时，系统会将该 API Key 写入本次龙虾部署配置中。

<figure><img src="../.gitbook/assets/Unknown image (46)" alt=""><figcaption></figcaption></figure>

## **15. 选择模型**

“选择模型”用于选择龙虾实例使用的 AI 模型。页面中以一个下拉框展示可选模型，例如“Kimi K2.5”。

用户点击下拉框后，可以从当前账号可用的模型中选择一个。该模型会作为龙虾实例默认调用的模型能力。模型选择会影响智能体回答效果、任务处理能力和可能产生的调用费用。

在选择模型时，应结合实际使用场景。如果用于日常问答或轻量任务，可以选择通用模型。如果用于复杂推理、代码、长文本处理等场景，可以选择能力更强的模型。实际可用模型以页面下拉框展示为准。

模型字段旁边可能存在提示图标。用户可以将鼠标移动到提示图标上，查看平台提供的补充说明。

<figure><img src="../.gitbook/assets/Unknown image (47)" alt=""><figcaption></figcaption></figure>

## **16. 选择渠道**

“选择渠道”用于选择龙虾实例部署时是否预配置消息渠道。页面中以一个下拉框展示当前可选渠道，默认可显示为“不配置”。

如果用户暂时不需要在部署阶段配置外部消息渠道，可以保持“不配置”。部署完成后，用户仍可以进入 OpenClaw 官方网页界面中按照官方说明进行渠道配置。OpenClaw 支持的渠道及其配置方法，请参考 OpenClaw 官方文档： [OpenClaw 官方文档](https://docs.openclaw.ai/zh-CN)。

交互逻辑如下：点击“选择渠道”下拉框，展开可选渠道；选择某个渠道后，该渠道会成为本次部署配置的一部分；保持“不配置”则表示创建龙虾时不预先设置消息渠道。

<figure><img src="../.gitbook/assets/Unknown image (48)" alt=""><figcaption></figcaption></figure>

## **17. 立即部署**

完成所有配置后，点击页面右下角的“立即部署”按钮，系统会根据当前页面中的配置创建龙虾实例。

点击“立即部署”前，建议用户确认以下信息：地区是否正确，机器规格是否符合需求，镜像版本是否正确，付费方式是否符合预期，虾群名称是否便于识别，龙虾数量是否正确，API Key 和模型是否已经选择。

点击按钮后，系统会提交创建请求并开始部署。部署过程中，用户可以进入“我的龙虾”页面查看新建虾群和龙虾实例的状态。实例刚创建完成时，状态可能显示为“启动中”。此时需要等待实例启动完成后再进入使用。

## **18. 我的龙虾页面概览**

点击左侧导航栏中的“龙虾管理 > 我的龙虾”，进入已创建龙虾的管理页面。该页面用于查看虾群列表、筛选龙虾实例、查看实例状态、复制 SSH 信息、进入 OpenClaw 网页界面，以及执行开机、释放实例等操作。

页面主要由四个区域组成：左侧虾群列表、顶部查询筛选区、中间龙虾列表与详情区、底部分页区。

<figure><img src="../.gitbook/assets/Unknown image (50)" alt=""><figcaption></figcaption></figure>

## **19. 左侧虾群列表**

页面左侧会展示“虾群名称”区域，其中包含“全部”和具体虾群名称。

点击“全部”时，页面右侧会展示当前账号下全部虾群中的龙虾实例。点击某个具体虾群名称时，页面右侧只展示该虾群下的龙虾实例。

如果虾群名称较长，页面可能会以省略号形式截断显示，例如“虾群17781442...”。用户可以根据名称前缀识别对应虾群。

交互逻辑如下：点击“全部”，查看所有虾群；点击某个虾群名称，切换到该虾群；被选中的虾群会有明显的高亮背景或左侧标识，表示当前列表正在展示该虾群内容。

<figure><img src="../.gitbook/assets/Unknown image (51)" alt=""><figcaption></figcaption></figure>

## **20. 查询筛选区**

“我的龙虾”页面顶部提供查询筛选功能，用户可以通过虾群名称和龙虾状态快速定位目标实例。

查询筛选区包含虾群名称输入框、龙虾状态下拉框、“重置”按钮和“查询”按钮。

<figure><img src="../.gitbook/assets/Unknown image (52)" alt=""><figcaption></figcaption></figure>

### 20.1 **虾群名称输入框**

虾群名称输入框用于输入想要查询的龙虾或虾群名称。用户点击输入框后，可以输入名称关键字。

输入后点击“查询”，页面会根据输入内容筛选列表。该功能适合在虾群较多时快速查找目标实例。

交互逻辑如下：点击输入框，输入关键字；点击“查询”；

列表刷新并展示符合条件的结果。如果没有匹配结果，页面可能显示为空列表或无数据提示。

### 20.2 **龙虾状态下拉框**

龙虾状态下拉框用于按照运行状态筛选实例。页面中默认提示为“请选择龙虾状态”。

用户点击下拉框后，可以选择需要筛选的状态。截图中展示的实例状态为“启动中”。实际可选状态以页面下拉框为准。

交互逻辑如下：点击状态下拉框，选择目标状态；

点击“查询”；列表刷新并展示符合该状态的龙虾实例。

### 20.3 **重置按钮**

“重置”按钮用于清空当前筛选条件。点击后，虾群名称输入框和状态筛选条件会恢复默认状态。

重置后，用户可以重新输入查询条件，也可以直接点击“查询”查看默认列表。

### 20.4 **查询按钮**

“查询”按钮用于执行当前筛选条件。用户设置虾群名称或状态后，需要点击“查询”才能刷新列表结果。

如果用户没有填写任何筛选条件，点击“查询”通常会展示默认列表或当前虾群范围下的全部结果。

## **21. 龙虾列表**

页面中部以列表形式展示龙虾实例。列表表头包括龙虾名称、状态、到期时间和操作。

“龙虾名称”显示当前实例或虾群的名称。名称较长时，页面可能以省略号截断显示。“状态”显示实例当前运行状态，例如“启动中”。“到期时间”显示实例服务到期时间。截图中到期时间显示为“0001-01-01 08:06:26”，实际以平台返回数据为准。“操作”区域提供进入和更多管理按钮。

## **22. 展开与收起龙虾详情**

每条龙虾记录左侧有一个展开或收起图标。点击该图标后，可以展开该龙虾的详细信息。再次点击可以收起详情。

展开后，页面会显示 SSH 命令、ROOT 密码、基础环境和运行状态等信息。该功能适合用户查看实例连接信息和运行配置。

交互逻辑如下：点击记录左侧展开图标，展示详情区域；详情区域展开后，图标状态发生变化；再次点击图标，详情区域收起。

## **23. SSH 命令**

详情区域中会显示 SSH COMMAND，即 SSH 连接命令。该命令用于通过 SSH 工具连接到对应龙虾实例。

SSH 命令区域右侧有复制按钮。点击复制按钮后，系统会将当前 SSH 命令复制到剪贴板。用户可以将复制的命令粘贴到终端工具中进行连接。

出于安全和展示需要，页面中部分 SSH 信息可能会被脱敏显示，例如用户名或域名部分以星号隐藏。用户应以复制结果或平台实际显示内容为准。

交互逻辑如下：展开龙虾详情；找到 SSH COMMAND 信息；点击右侧复制按钮；复制成功后，将命令粘贴到本地终端或 SSH 客户端中使用。

<figure><img src="../.gitbook/assets/Unknown image (55)" alt=""><figcaption></figcaption></figure>

## **24. ROOT 密码**

详情区域中会显示 ROOT PASSWORD，即实例 root 用户密码。页面会以圆点或星号形式隐藏密码内容，避免明文暴露。

ROOT 密码区域右侧同样提供复制按钮。点击复制按钮后，系统会将密码复制到剪贴板。用户通过 SSH 连接实例时，可以使用该密码完成登录或授权。

由于 ROOT 密码属于敏感信息，请妥善保管，不要公开分享，也不要粘贴到不可信页面中。

交互逻辑如下：

展开龙虾详情；

找到 ROOT PASSWORD 信息；

点击复制按钮；

在需要输入密码的位置粘贴使用。

该区域主要用于查看，不提供直接编辑功能。如果用户需要更改镜像、模型等配置，通常需要通过重新创建实例或进入相关配置页面完成。

交互逻辑如下：确认龙虾实例已经启动完成；点击“进入”；浏览器打开 OpenClaw 网页界面；后续按照 OpenClaw 官方文档继续操作。

## **28. 更多操作**

“进入”按钮旁边有更多操作按钮，通常以三个点图标展示。点击该按钮后，会展开更多可用操作。

根据当前页面信息，更多操作中包含“开关机”和“释放实例”等操作。不同实例状态下可用操作不同。例如，实例运行时提供“关机”；实例未运行时提供“开机”；不再需要实例时可以选择“释放实例”。

### 28.1 **开关机**

“开关机”用于启动/关闭当前龙虾实例。当实例处于关闭或运行状态时，用户可以通过该操作启动/关闭实例。

交互逻辑如下：

系统提交开关机请求；

实例状态进入启动/关机过程。

如果实例正在启动中，用户应等待启动完成，不建议重复触发操作。

### 28.2 **释放实例**

“释放实例”用于释放当前龙虾实例资源。当用户不再需要某个实例时，可以执行释放操作。

释放实例通常会导致该实例不可继续使用，并可能清理相关云端资源。执行该操作前，用户应确认不再需要该实例中的数据和服务。

交互逻辑如下：点击更多操作按钮；选择“释放实例”；根据页面提示确认释放；系统提交释放请求；释放完成后，该实例从列表中移除。

## **30. 分页功能**

页面底部提供分页功能，用于在龙虾实例较多时切换列表页。分页区域包括上一页、下一页、页码和每页条数选择。

页码按钮用于展示当前所在页，例如“1”。上一页和下一页按钮用于切换页面。如果当前只有一页数据，上一页或下一页按钮可能不可用。

每页条数下拉框用于设置每页展示的记录数量，例如“10 条/页”。用户点击该下拉框后，可以选择其他每页展示数量。选择后，列表会按照新的分页数量刷新。

## **31. 从创建到进入的推荐流程**

用户首次使用 OpenClaw 龙虾农场时，可以按照以下流程完成部署和进入。

首先，进入“龙虾管理 > 创建龙虾”页面，选择部署地区、机器规格和镜像版本。

然后，根据需要设置扩展盘大小、付费方式、虾群名称和龙虾数量。

接着，选择 API Key、模型和渠道配置。确认页面顶部的资源概要和费用信息无误后，点击“立即部署”。

部署提交后，进入“龙虾管理 > 我的龙虾”页面，找到刚刚创建的虾群和龙虾实例。实例刚创建时可能显示为“启动中”，此时需要等待启动完成。实例可用后，点击“进入”按钮，即可打开 OpenClaw 网页界面。

进入 OpenClaw 网页界面后的操作不在本文档范围内，请参考 OpenClaw 官方文档： [OpenClaw 官方文档](https://docs.openclaw.ai/zh-CN)。

## **32. 多个龙虾实例的使用说明**

创建龙虾时，用户可以通过“龙虾数量”滑块一次性部署多个龙虾实例。多个实例会归属于同一个虾群，便于统一查看和管理。

这种方式适合需要同时运行多个智能体任务的场景。例如，用户可以为不同项目、不同团队、不同客户或不同自动化任务分配独立的龙虾实例。

部署多个实例时，需要特别关注服务器数量和费用信息。页面顶部的“服务器数量”和右上角费用会反映当前配置情况。确认无误后再点击“立即部署”。

在“我的龙虾”页面中，用户可以通过左侧虾群列表查看某个虾群下的实例，也可以通过“全部”查看所有虾群中的实例。

## **33. 费用与资源确认**

创建龙虾前，用户应关注页面右上角的费用展示。费用会受到机器规格、付费方式、扩展盘大小、龙虾数量等因素影响。

如果选择按月付费或按年付费，页面可能展示对应服务周期和到期时间。如果选择按量付费，则费用会根据实际使用规则计算，页面会展示当前配置下的费用提示。

在点击“立即部署”前，请务必确认费用和资源配置。如果不再需要某个实例，可以在“我的龙虾”页面通过更多操作中的“释放实例”释放资源。

## **34. 常见问题**

### 34.1 **为什么点击“进入”没有反应或按钮不可用？**

如果龙虾状态显示为“启动中”，说明实例尚未完全启动。此时“进入”按钮可能不可用。请等待实例启动完成后再尝试进入。

### 34.2 **创建时应该选择哪个镜像？**

一般建议使用页面默认推荐的 OpenClaw 镜像版本。平台提供多个镜像，请根据业务需要选择。普通用户可以优先保持默认选项。

### 34.3 **没有可用的 API Key 怎么办？**

如果 API Key 下拉框中没有合适选项，请先到控制台左侧“API 密钥”页面创建或配置 API Key，然后返回“创建龙虾”页面重新选择。

### 34.4 **渠道选择“不配置”会影响部署吗？**

选择“不配置”表示创建龙虾时不预先配置消息渠道。龙虾仍然可以部署。部署完成后，用户可以进入 OpenClaw 网页界面，根据 OpenClaw 官方文档继续配置渠道。

OpenClaw 官方文档地址： [OpenClaw 官方文档](https://docs.openclaw.ai/zh-CN)。

### 34.5 **如何释放不再使用的龙虾？**

进入“我的龙虾”页面，找到目标实例，点击操作区域中的更多操作按钮，选择“释放实例”。释放前请确认该实例不再需要使用，并注意保存必要数据。
